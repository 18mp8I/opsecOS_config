# opsecOS_config
opsecOS_config.sh is a file for setting up opsecOS on TinyCoreOS (CorePlusx84_54 Version)
And this is how:
- 1. Install CorePlus and Run It
- 2. Then open the Wifi app and connect to wifi the OS
- 3. Then run the app named "tc-install"
- 4. Select "Whole Disk" and select your principal Disk
- 5. Click next three times (The second arrow) and select all the extensions
- 6. After the installation has been finished reboot the system (Optional)
- 7. Then open the app manager and install git
- 8. For the final step do this:
     Open the terminal,
     And type this commands:
         "git clone https://github.com/18mp8I/opsecOS_config/"
         "cd opsecOS_config"
         "sh opsecOS_config.sh"
